# FISPOD — журнал нормативной верификации

Дата среза: 26.11.2026  
Основной акт: приказ МО РФ от 20.04.2023 № 230, консолидированная редакция от 08.12.2025.

## Проверено и внесено в код
- Приложение № 5: перечень упражнений № 1–70 и группировка по разделам.
- Упражнения № 1–70: исходные положения, последовательность, условия зачёта, оборудование, ограничения допуска и номера официальных рисунков (ссылки на оригинальные рисунки остаются в источнике).
- Таблицы перевода результата в баллы для упражнений № 1–52 и № 54–70. Упражнение № 53 — комплекс технических действий, для которого предусмотрены критерии оценки, а не единая таблица результата.
- Приложение № 12: пороги индивидуальной оценки «5», «4», «3» вынесены в отдельный модуль `src/data/evaluation-thresholds.ts`; отдельно представлены призывники-мужчины, контрактники по возрасту и курсанты обоих полов. Для женщины-призывника и возраста мужчины-контрактника ровно 60 лет автоматический расчёт заблокирован. Добавлены граничные тесты по всем возрастным строкам и курсам.
- Приложение № 11: установлено, что учитывается одна из предусмотренных поправок — для районов Крайнего Севера/приравненных территорий либо высоты свыше 1500 м. Полная таблица ещё не встроена в расчётный движок.
- Приложение № 6: подтверждены минимальные баллы и пороги общей оценки в просмотренных строках; полная таблица и все категории требуют переноса.

## Функциональность в ветке feature/fispod-foundation
- Адаптивная оболочка, мобильная боковая навигация.
- Справочник 70 упражнений, поиск, фильтрация, избранное.
- Карточки техники № 1–70; в карточках специальных упражнений отражены допуск по специализации, экипировка, последовательность и условия невыполнения.
- Калькулятор для № 1–52 и № 54–70: только точное совпадение с официальной таблицей; интерполяция отключена. Поддержаны весовые категории для № 10–12 и № 14–16; возрастные колонки для № 17–19, № 23–29 и № 45; профили курсантов и родов авиации для специальных упражнений. Форматы ввода включают ММ:СС, секунды с десятыми, количество повторений, дальность метания, попадания и номер варианта.
- Локальные карточки с датой рождения, полом и категорией службы; возраст рассчитывается на дату проверки.
- История результатов по каждому военнослужащему; редактирование и удаление результатов, удаление карточек.
- Экспорт журнала в CSV для Excel и печать истории в PDF через системный диалог.
- Конспект раздела II (пункты 11–79): организация, планирование, методика обучения, контроль, учёт, безопасность, формы физподготовки и особые климатические условия.
- Резервное копирование JSON с проверкой файла и восстановлением локальных карточек, результатов и избранного.
- Защита CSV-экспорта от запуска формул в табличном редакторе.
- Тренажёр нумерации, экспорт резервной копии JSON.
- PWA manifest и service worker shell.
- Vitest и GitHub Actions: набор тестов проверяет точные строки таблиц, граничные значения, возрастные и весовые категории, специальные профили и карточки упражнений; последний результат CI будет указан после проверки текущей версии.

## Нормативная сверка приложения № 6 и пунктов 81–83 (26.11.2026)

Повторно сверено с актуальной консолидированной редакцией приказа № 230 от 08.12.2025:
- Приложение № 6 содержит 20 логических колонок: минимум за одно упражнение; три порога оценки для каждого количества упражнений от двух до пяти; четыре порога квалификационных уровней.
- Для призывников-мужчин общая оценка предусмотрена при 3 и 4 упражнениях; минимум за каждое упражнение — 26 баллов.
- Для курсантов-мужчин 1 курса общая оценка предусмотрена при 4 упражнениях, для 2-го и последующих курсов — при 5 упражнениях; минимумы соответственно 30, 34 и 38 баллов.
- Для контрактников возрастных групп 1–6 (до 49 лет) общая оценка «5/4/3» дана при 3 упражнениях для категорий 1–3; для категории 1 дополнительно дана оценка при 4 упражнениях. Минимумы по возрастным группам: 30, 28, 26, 22, 20 и 16 баллов.
- Для контрактников возрастных групп 7–9 (50 лет и старше) таблица задаёт оценку при 2 упражнениях, минимумы 12, 10 и 8 баллов.
- Для курсантов женского пола и военнослужащих женского пола таблица задаёт общую оценку при 3 упражнениях для возрастных групп до 44 лет; для женских возрастных групп 45–49 и 50+ — при 2 упражнениях. Минимумы и пороги приведены в первоисточнике.
- В строках контрактников категории 1 квалификационные значения отображаются в источнике парами/группами, связанными с числом упражнений. Плоский текстовый экспорт смешивает границы ячеек. Эти значения нельзя переносить как четыре простых числа без сверки визуальной структуры таблицы; автоматическое присвоение квалификационного уровня пока не реализовано.

Правила раздела II:
- Пункт 81: требование считается выполненным, если военнослужащий оценён не ниже «удовлетворительно».
- Пункт 82: общая оценка и квалификационный уровень определяются по сумме баллов с обязательным соблюдением минимума в каждом упражнении по приложению № 6.
- Пункт 83: «неудовлетворительно» выставляется, если упражнение не выполнено, минимум не набран хотя бы в одном упражнении либо общая сумма ниже порога «удовлетворительно».

Практическое следствие для будущего калькулятора: сначала проверяется выполнение каждого упражнения и его индивидуальный минимум; только после этого сумма сопоставляется с порогом для конкретной категории и количества упражнений. Одной суммы баллов недостаточно. Квалификационный уровень должен рассчитываться отдельной проверенной веткой и не выводиться из порогов общей оценки.

## Комплексная оценка — первая реализация (26.11.2026)

Добавлен модуль `src/data/complex-evaluation.ts` на основании приложения № 6:
- призывники-мужчины: 3 или 4 упражнения;
- курсанты-мужчины: 1 курс — 4 упражнения, 2-й и последующие — 5;
- контрактники-мужчины: возрастные группы 1–6 с отдельными категориями 1–3; группы 7–9 — 2 упражнения;
- курсанты и военнослужащие женского пола: возрастные/курсовые строки и предусмотренное таблицей количество упражнений;
- проверка минимального количества баллов в каждом упражнении до проверки суммы;
- отдельные тесты по категориям, возрастным группам, количеству упражнений, минимальному баллу и неудовлетворительной сумме.

Добавлен экран «Комплексная оценка» и подключён в навигацию. Он принимает результат для каждого упражнения, переводит его в баллы по доступным проверенным таблицам приложения № 5 (сейчас № 1–19 и № 20–29), после чего применяет приложение № 6. Неподдерживаемое число упражнений и отсутствующая таблица блокируют расчёт.

**Ограничения:** квалификационные уровни не рассчитываются; не все балльные таблицы упражнений перенесены; отдельные сочетания категорий и числа упражнений отсутствуют в приложении № 6 и намеренно не поддерживаются. Для контрактников-мужчин нужен явный номер категории 1–3. Женщины-призывники не поддерживаются, так как отдельная строка в приложении № 6 отсутствует.

## Защита от ложных результатов

Добавлены карточки специальных упражнений № 39–44 и их точные балльные таблицы. Внесены исходные положения, экипировка, порядок старта, дистанции и критерии невыполнения. Таблицы № 39–40 используют разреженные значения секунд; № 41–44 — точные времена в секундах после преобразования ММ:СС. Неуказанные значения не интерполируются. Калькулятор принимает время ММ:СС для № 41–44 и секунды для № 39–40.

Добавлены специальные упражнения № 45–52: общая полоса препятствий, три курсантских контрольных маршрута, упражнения для ВДВ, флота и горных подразделений, а также общая специальная и морская полосы. Для № 45 внесена возрастная таблица; № 46–49 и № 51–52 получили точные временные шкалы; № 50 — отдельную шкалу с нерегулярным шагом. Калькулятор требует выбрать профиль применимости для № 46–50 и № 52, чтобы не рассчитывать чужие нормативы.

Добавлено упражнение № 45 — общее контрольное упражнение на единой полосе препятствий. Перенесена таблица времени с двумя возрастными колонками; сохранены разрывы в баллах и все отсутствующие значения. В карточке описана последовательность препятствий, метание гранаты 600–620 г и штраф 5 секунд за каждый промах. Ввод времени — ММ:СС, возраст выбирает нормативную колонку.

Добавлены карточки № 53–70. № 53 представлен как справочная карточка комплекса рукопашного боя без пошагового воспроизведения боевых действий; числовой таблицы для него нет. Для № 54–55 подключена официальная шкала 1/2/3 засчитанных попадания = 40/70/100 баллов. Для № 56–57 подключены точные таблицы плавания в обмундировании с оружием, для № 58 — таблица дистанции ныряния. В карточках водных упражнений добавлены отдельные предупреждения о спасательном обеспечении и запрете одиночного выполнения.


## Завершение базы упражнений № 59–70

Добавлены карточки специальных упражнений № 59–70 и подключены точные балльные таблицы для № 59–64 и № 66–70; для № 65 используется вариант выполнения 1/2/3 с баллами 40/70/100 и обязательным выбором рода авиации. В калькуляторе поддержаны форматы ММ:СС, десятые доли секунды, количество повторений, дальность броска и число попаданий. Для № 59 учитываются штрафы за промахи в стрельбе и метании; для № 61 — штраф 2 секунды за непопадание макета гранаты в сектор.


## Полнота нормативного калькулятора

В калькуляторе представлены все числовые таблицы приложения № 5 для упражнений № 1–52 и № 54–70. № 53 хранится как отдельный комплекс технических действий с критериями, поскольку его результат не сводится к одной числовой таблице. Никакая интерполяция между строками не выполняется. Для специальных упражнений 46–52 и 65 предусмотрен контроль соответствия выбранной специализации.

## Актуальная сводка проекта (26.11.2026)

Этот раздел имеет приоритет над более ранними списками незавершённых задач выше: они отражают промежуточные этапы разработки.

- Индекс и подробные карточки техники: упражнения № 1–70.
- Числовые таблицы приложения № 5: упражнения № 1–52 и № 54–70 (69 упражнений). № 53 не имеет единой числовой шкалы и не рассчитывается как обычное числовое упражнение.
- Индивидуальный калькулятор использует точные строки таблиц и пороги приложения № 12; промежуточные значения не интерполируются. Добавлен единый парсер времени ММ:СС и десятичных секунд.
- Комплексная оценка приложения № 6: поддержанные категории, число упражнений и минимум за каждое упражнение. Повторное включение одного упражнения в расчёт запрещено.
- Журнал, CSV, печать в PDF через системный диалог, резервное копирование JSON, учебный конспект, тренажёр и PWA сохранены.
- Добавлена подготовка к публикации на GitHub Pages; для фактической публикации необходимо объединить ветку в main и выбрать GitHub Actions в Settings → Pages.

Остаются ограничениями: автоматические поправки приложения № 11, квалификационные уровни по приложению № 6, полный автоматический анализ обязательных упражнений и замен, локальные изображения официальных рисунков. Возраст 60 лет у мужчин-контрактников остаётся заблокированным в индивидуальном калькуляторе из-за пересечения возрастных интервалов в опубликованной таблице.

Нормативная база в коде: приказ МО РФ № 230 в редакции от 08.12.2025; изменения приказа № 802 действуют с 02.02.2026. Перед служебным использованием необходима сверка с действующим официальным текстом.

## Модуль «Анализ требований» (26.11.2026)

- Вместо заглушки реализован расчёт структуры проверки по пункту 88 раздела II действующей редакции приказа № 230.
- Поддержаны военнослужащие по контракту (мужчины и женщины), курсанты 1-го и последующих курсов.
- Для мужчин-контрактников до 50 лет учитываются категории 1–3; для возрастных групп 7–9 применяется комплект из двух ОФУ независимо от категории.
- Для женщин учитывается переход с трёх ОФУ на два ОФУ с 45 лет.
- Для курсантов 1-го курса выводится комплект 3 ОФУ + 1 СФУ; для 2-го и последующих курсов — 3 ОФУ + 2 СФУ с указанными в пункте 88 вариантами.
- Для призывников не угадывается комплект: пользователь должен выбрать 3 или 4 упражнения, поскольку приказ связывает это с подразделением.
- Для каждого блока отображаются допустимые физические качества и справочные упражнения приложения № 5. Конкретные СФУ не назначаются автоматически вместо программы подразделения.
- Мобильный интерфейс модуля адаптирован: сворачиваемые списки упражнений, вертикальные карточки, удобные поля выбора.
- Отдельно отмечено, что IIIа/IIIб группы здоровья и инвалидность требуют дополнительного сценария и проверки медицинских оснований.
