# FISPOD — план разработки

## Цель
Локальное веб-приложение для личной работы инструктора по физической подготовке. Приоритеты: нормативная достоверность, воспроизводимые расчёты, проверяемое происхождение данных, затем интерфейс.

## Этапы
1. Нормативный аудит: собрать консолидированный текст приказа МО РФ от 20.04.2023 № 230, проверить изменения, приложения, таблицы, примечания и иллюстрации.
2. Модель данных: упражнения, категории, условия допуска/замены, нормативные таблицы, балльные шкалы, правила итоговой оценки, поправки и ссылки на источник.
3. Вычислительное ядро: чистые функции без UI-зависимостей; строгая обработка единиц, границ диапазонов, возраста на дату проверки и отсутствующих значений.
4. Тестирование: контрольные примеры из документа, граничные значения, регрессионные тесты для каждой таблицы и правила расчёта.
5. Интерфейс: справочник, калькулятор, анализ требований, комплексная оценка, журнал, обучение, шпаргалка, настройки.
6. PWA и локальные данные: IndexedDB, офлайн-кэш, экспорт/импорт резервной копии, Excel и PDF.
7. Приёмка: сверка всех отображаемых нормативов с источником; список неподтверждённых данных должен быть пустым для функций, заявленных как готовые.

## Технологический ориентир
- React + TypeScript + Vite
- IndexedDB (Dexie или аналог)
- PWA / Service Worker
- Вычислительное ядро в отдельном пакете/модуле
- Vitest для unit- и regression-тестов
- ExcelJS для XLSX; отдельный модуль экспорта PDF

## Правила достоверности
- Никаких придуманных нормативов, баллов, замен и правил интерполяции.
- Каждое нормативное значение хранит ссылку на пункт, приложение, таблицу/строку и редакцию документа.
- Неизвестное значение хранится как отсутствующее/непроверенное, а не как ноль.
- Фото/схемы из нормативного документа сохраняются с привязкой к упражнению и странице. Дополнительные учебные иллюстрации явно маркируются как поясняющие, а не официальные.
- Любое изменение нормативной базы сопровождается версией источника и регрессионными тестами.
