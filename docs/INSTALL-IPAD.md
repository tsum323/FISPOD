# Установка FISPOD на iPad

## Подготовить сборку
1. На компьютере установи Node.js 20 или новее.
2. В корне репозитория выполни `npm install`.
3. Выполни `npm run build`.
4. Содержимое каталога `dist` размести на статическом HTTPS-хостинге.

## Установить на iPad
1. Открой опубликованный HTTPS-адрес в Safari.
2. Дождись первой полной загрузки приложения.
3. Нажми «Поделиться» → «На экран Домой».
4. Подтверди добавление. Запускай FISPOD с иконки на домашнем экране.
5. После первого запуска проверь работу в авиарежиме.

## Важные ограничения
- Для установки PWA на iPad нужен HTTPS-адрес; обычный HTTP-адрес другого устройства в локальной сети не является надёжным вариантом для установки.
- Данные журнала хранятся локально в браузере/контексте установленного приложения. Они не синхронизируются между iPad и компьютером автоматически.
- Перед очисткой данных Safari, переустановкой или сменой устройства экспортируй резервную копию JSON.
- Экспорт CSV открывается в Excel; PDF можно получить через системную печать.
- Полноценную работу офлайн следует проверять после первой загрузки всех экранов и ресурсов. Service worker кэширует приложение и same-origin ресурсы по мере загрузки.

## Локальный запуск на компьютере
`npm run dev` — режим разработки. Для постоянного использования собери production-версию через `npm run build` и размести `dist` на HTTPS-хостинге.
