# Установка FISPOD на iPad

## Публикация через GitHub Pages

1. Открой Pull Request из ветки feature/fispod-foundation в main и после проверки объедини его.
2. В репозитории открой Settings → Pages.
3. В разделе Build and deployment выбери Source: GitHub Actions.
4. После успешного workflow открой адрес https://tsum323.github.io/FISPOD/.
5. Открой опубликованный адрес в Safari на iPad.
6. Нажми «Поделиться» → «На экран Домой» и подтверди добавление.

## Проверка

- Дождись первой полной загрузки приложения, затем перезагрузи страницу.
- Проверь, что приложение открывается с иконки на домашнем экране.
- После первой загрузки проверь основные экраны в авиарежиме.

## Хранение данных

- Карточки военнослужащих, результаты и избранное хранятся локально в браузере/контексте установленного приложения.
- Данные не синхронизируются между iPad и компьютером автоматически.
- Перед очисткой данных Safari, переустановкой или сменой устройства экспортируй резервную копию JSON.
- Экспорт CSV открывается в Excel; PDF можно получить через системную печать.

## Локальный запуск

1. Установи Node.js 20 или новее.
2. В корне репозитория выполни npm install.
3. Выполни npm run dev и открой адрес, который покажет Vite.
4. Для локальной production-проверки выполни npm run build и npm run preview.

## Важное ограничение офлайн-режима

Service worker кэширует оболочку приложения и same-origin ресурсы по мере их загрузки. Полноценную работу офлайн проверяй после первой загрузки всех экранов и ресурсов.
