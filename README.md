# Физподготовка | Instructor

Личное адаптивное веб-приложение инструктора по физической подготовке. Работает как PWA; личные записи хранятся локально в браузере.

## Что реализовано

- Справочник всех 70 упражнений приложения № 5: поиск, фильтрация и избранное.
- Подробные карточки упражнений № 1–70: исходное положение, последовательность, правила зачёта, оборудование, номер официального рисунка и переход к первоисточнику.
- Индивидуальный калькулятор баллов: числовые таблицы приложения № 5 для упражнений № 1–52 и № 54–70; упражнение № 53 не имеет единой числовой шкалы. Поддержаны точные значения, возрастные и весовые категории, курсы и специальные профили. Интерполяция и экстраполяция запрещены.
- Комплексная оценка по приложению № 6: проверка минимума за каждое упражнение и суммы баллов для поддержанных категорий и количества упражнений.
- Локальный журнал военнослужащих: карточки, возраст на дату проверки, история результатов, редактирование и удаление записей.
- Экспорт журнала в CSV для Excel и печать истории в PDF через системный диалог.
- Резервное копирование и восстановление карточек, результатов и избранного в JSON.
- Учебный конспект раздела II (пункты 11–79) и тренажёр случайного сопоставления номера упражнения и названия.
- Адаптивная боковая навигация и PWA manifest/service worker для установки на iPhone/iPad.

## Локальный запуск

1. Установить Node.js 20 или новее.
2. Выполнить команду npm install.
3. Выполнить команду npm run dev.
4. Открыть адрес, который покажет Vite.

## Публикация и установка на iPad

См. [инструкцию по установке PWA](docs/INSTALL-IPAD.md). Для установки на главный экран и работы service worker требуется production-сборка на HTTPS-хостинге. Ветка GitHub сама по себе не является опубликованным сайтом.

## Ограничения, которые важно учитывать

- Приложение № 11 (поправки для особых условий местности) пока не применяется автоматически.
- Квалификационные уровни не рассчитываются: для отдельных строк приложения № 6 требуется дополнительная визуальная проверка объединённых ячеек.
- Анализ обязательных упражнений и замен по всем категориям пока не автоматизирован.
- В карточках указаны номера официальных рисунков и ссылки на нормативный источник; локальные изображения из приказа не встроены.
- Для возраста ровно 60 лет у мужчин-контрактников автоматический выбор порога приложения № 12 заблокирован из-за пересечения возрастных интервалов в опубликованной таблице.
- Перед служебным применением проверяй действующую редакцию приказа и условия проведения проверки. Приложение — рабочий справочный инструмент, а не замена нормативному документу.
