# Физподготовка | Instructor

Личное веб-приложение инструктора по физической подготовке.

## Запуск локально
1. Установить Node.js 20 или новее.
2. Выполнить `npm install`.
3. Выполнить `npm run dev`.
4. Открыть адрес, который покажет Vite.

## Текущее состояние
- Рабочая адаптивная оболочка и навигация.
- Справочник всех 70 упражнений по приложению № 5 (пока проверен перечень и названия).
- Поиск и фильтрация.
- Избранное и карточки личного учёта в локальном хранилище браузера.
- Тренажёр случайного сопоставления номера и названия.
- Экспорт локальной резервной копии JSON.
- Расчётные модули намеренно заблокированы до переноса и построчной проверки нормативных таблиц.

## Нормативный источник
Приказ Министра обороны РФ от 20.04.2023 № 230, редакция от 08.12.2025.
- [Консолидированный текст](https://www.consultant.ru/document/cons_doc_LAW_450143/)
- [Приложение № 5 — упражнения](https://sudact.ru/law/prikaz-ministra-oborony-rf-ot-20042023-n_1/prilozhenie/prilozhenie-n-5/)

## Важно
Перечень упражнений — не то же самое, что полная нормативная база. До завершения проверки карточек упражнений, балльных таблиц, приложений № 6, 11, 12 и 14, а также правил замен нельзя использовать приложение для выставления официальных баллов и итоговых оценок.
